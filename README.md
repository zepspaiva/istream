# iStream

Watch from the sofa without the TV remote: browse on an iPhone or iPad, tap, and the TV wakes and plays.

| Folder | What it is |
| --- | --- |
| `tv/` | The TV app: [Free My TV](https://github.com/simbasjungles/free-my-tv) (launcher + player), with our changes |
| `ios/` | The iPhone and iPad app (SwiftUI) |
| `pi/` | The Raspberry Pi backend for now (Docker): TV service and content API, plus TV test tools |
